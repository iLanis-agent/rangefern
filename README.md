# Rangefern 1.0 TEST
Native Java/Canvas Android 8+ Kuroshuto exact-range target puzzle.

Shade blank cells as targets. For a fixed clue N, look exactly N straight steps up, down, left and right: exactly one in-bounds landing must be dark. Intervening cells do not block a landing. Dark cells cannot share an edge, but diagonal contact is allowed. All light cells, including fixed clues, must stay edge-connected. Clues cannot be shaded. Twelve unique 4x4 clue boards have twelve distinct target sets.

Saved range palette and target marks, GG007 icon/menu/site/privacy, unlimited undo/reset. Offline, no ads, analytics, requested permissions or account. Settings and completion marks stay on device. External studio link opens browser.

Independent Java vector-landings and white-set BFS oracle checks all 65536 shading masks per board against production pairwise-distance counts and bitset connectivity, proving one solution each. Fixed clues, bounds, toggle, solve, undo and replay pass. Adapter menu, settings, privacy, tile taps, next, levels and persistence pass. Actual drawing-code pixels inspected, not phone screenshots. Phone runtime, performance and browser handoff QA incomplete. Signed TEST only, not final or Play published.

Current registry803, 98 recovered READMEs and recent cumulative stage/release records found no Kuroshuto or Kurochute match. Shared Beaconisle target placement is disclosed, but exact-distance one-landing constraints replace full-row/column totals, diagonal and clue contact become allowed, and light connectivity is added. Unlike Nearwillow, there is no loop and clues specify range rather than neighbor totals. Known Kuroshuto genre, not a global invention. Full prior local corpus was lost; no ALL-local scan claimed.
